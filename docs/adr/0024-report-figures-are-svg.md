# ADR-0024 — Report figures are SVG written from the pinned stack, not PNG from matplotlib

**Status:** accepted · **Milestone:** M7

## Context

Appendix D names four figures and gives them `.png` extensions:

```
figures/
  reliability.png       with bin-count histogram underneath
  ablation_forest.png   effect sizes with CIs
  convergence.png       p_hat stability vs replicate count
  sigma_vs_error.png    the "sigma is informative" claim, tested
```

The pinned stack (§2.3) is Python 3.12, LangGraph, PostgreSQL + pgvector,
bge-small, two Claude models, Langfuse, DuckDB + Parquet, Typer + Rich, uv +
Docker Compose, pytest + hypothesis. There is no plotting library in it, and
`pyproject.toml` declares none. §3 of CLAUDE.md is explicit: *"If you believe a
substitution is warranted, write an ADR in `docs/adr/` and ask. Do not swap
silently."*

`matplotlib`, `scipy` and `scikit-learn` are all importable in this
environment. None of them is declared: they arrive as transitive dependencies
of `sentence-transformers`, which is in the optional `embed` extra. A figure
that imported matplotlib would work on this machine, work in CI while the embed
extra is installed, and fail on a clean checkout of the declared dependency set
— which is the configuration a reproduction attempt starts from.

## Decision

The four figures are written as **SVG**, generated by `cascade/eval/figures.py`
from the standard library. No plotting dependency is added.

Every function is pure: it takes measured values and returns a document string.
Nothing in the module computes a statistic — a figure that recomputed its own
data would be a second implementation of a metric, and the two would eventually
disagree in the direction nobody checks.

`manifest.json` records the figure format so a reader of the artifact does not
have to infer it from a directory listing.

## Consequences

**What is gained.** The artifact is reproducible from the declared dependency
set alone. The figures are vector, so they are legible at any zoom in a
reviewer's PDF. They are also text, so `git diff` on a re-run of the report
shows which numbers moved — a property no raster format has, and a useful one
for an artifact the spec says is committed.

**What is given up.** No raster fallback: a consumer that must have PNG has to
convert. Anti-aliased marker rendering is the browser's rather than a plotting
library's. And every chart type this project needs must be written here, which
bounds how many chart types it is reasonable to want — four is affordable,
forty would not be.

**The deviation is recorded rather than hidden.** Appendix D says `.png`; the
files are `.svg`. `manifest.json` names the deviation and this ADR is its
reasoning.

## The same reasoning applied elsewhere in M7

`metrics.py` and `stats.py` implement AUC with mid-ranks, the Wilson interval,
isotonic regression by pool-adjacent-violators, Holm–Bonferroni, and
permutation p-values from their definitions rather than calling scipy or
scikit-learn. These are the numbers the study *is*; a headline Brier that
depends on an undeclared package is a headline that cannot be reproduced. It is
the same argument ADR-0021 made for the dip test, and it is stronger here.
